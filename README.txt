DRAKO - publish on GitHub Pages
1. Create a PUBLIC repository on github.com (for example "drako").
2. Upload EVERYTHING from this folder, keeping the "img" folder:
   index.html, manifest.webmanifest, sw.js, three icon files and the img folder.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Open https://YOUR-USERNAME.github.io/drako/ and install it:
   Chrome/Edge: install icon in the address bar. iPhone: Share > Add to Home Screen.
5. Open the app once while online. After that it works offline.
To update later: upload the changed files and change the version number in sw.js.
